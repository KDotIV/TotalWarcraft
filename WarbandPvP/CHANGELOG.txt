TotalWarcraft 0.7.10
November 23, 2026 - Release - WoW Forever 1.60.1

- Restore strict verification after combat. Forever can hide the native damage
  attribution that 0.7.9 required during combat, preventing automatic reports.
- Keep the observed opponents and fight location when combat ends or the player
  dies. Read damage only after combat and lockdown clear, starting around half
  a second after combat ends with up to three bounded checks.
- Readable incoming OR outgoing damage attributed to an observed opposing player
  can qualify. NPC/pet, duel, instance, identity and shared-cooldown guards remain.
  Targets, combat flags and aggregate damage totals alone never qualify.
- Short fights can report after combat. Resumed combat and context changes cancel
  pending reads. Reports use the captured fight location rather than a graveyard.
- Session logs identify post-combat verification and waits for combat lockdown.
- Offline regression tests cover the corrected flow; live verification is still
  required before claiming successful reporting on the current client.

TotalWarcraft 0.7.9
November 23, 2026 - Release - WoW Forever 1.60.1

- Automatic captures check for PvP activity every five seconds during combat.
  New readable incoming OR outgoing damage attributed to an observed opposing
  player can trigger a report while the fight continues.
- Ending combat cancels the pending check. Fights ending before a successful
  check do not send a delayed automatic report; already sent reports remain.
- NPC/pet, duel, instance, identity and shared two-minute cooldown safeguards
  remain. Each combat has at most one automatic submission attempt.
- Reports use the current location when submitted. Session logs show combat
  checks, damage direction, missing sessions and unavailable attribution.
- Forever restricts native damage details during combat. Unreadable attribution
  skips the report; live in-combat reporting still needs client verification.

TotalWarcraft 0.7.7
November 22, 2026 - Release - WoW Forever 1.60.1

  to send and receive activity across zones and continents on matching rulesets.

TotalWarcraft 0.7.6
November 22, 2026 - Release - WoW Forever 1.60.1

- Automatic PvP reports now require incoming damage attributed to an observed,
  attackable, PvP-flagged opposing player. Combat state and targeting alone no
  longer trigger an automatic report.
- Damage checks run after combat using a fresh native combat session. NPC/pet
  damage, ambiguous identities, duels and unavailable attribution do not qualify.
- Incoming damage is sufficient; reporting does not wait for outgoing damage.
  An accepted report remains valid if another fight starts afterward.
- Automatic reports retain the captured fight location. Manual reports and
  keybindings remain available, with the shared two-minute reporting cooldown.

TotalWarcraft 0.7.5
November 21, 2026 - Release - WoW Forever 1.60.1

- Warband maintenance sleeps when discovery is off and no queue or owned Finder
  listing needs cleanup. Active maintenance runs once per second; the 250ms send
  timer runs only while messages are queued, with the same transmission limit.
- Scouting cleanup starts only when there are requests, snapshots or rate-limit
  entries to expire, then stops. No remote-detection experiment is included.
- Automatic reports stop polling after their one attempt for the current combat.
  Manual and automatic submissions now retain the correct local origin flag.
- Group Locations and command-board counts refresh when shared locations arrive,
  expire or leave the native roster. Clearing reports stops their expiry timer.
- Removed a redundant release-only empty-note helper. Development fixtures remain
  separate from production. Report, invitation and layer-evidence rules are unchanged.
- Public packages exclude dummy parties, developer diagnostics and remote tester
  controls. All 17 offline suites pass, including the compiled production build.

Known limit: automatic reports are observations, not verified player-to-player
damage. Native permissions, cross-faction delivery and layer arrival still need
live validation. This release does not add a damage-verification feature.

TotalWarcraft 0.7.4
November 21, 2026 - Release - WoW Forever 1.60.1

RENAMED TO TOTALWARCRAFT
- Updated the addon title, command board, keybinding category, help, messages,
  session exports and documentation to TotalWarcraft.
- /tw is the main command. /totalwarcraft and the existing /wb also work.
- Existing settings, keybindings and message compatibility are preserved.
  The internal WarbandPvP folder remains the same for seamless updates.
- The public package excludes developer commands, dummy parties and remote
  tester controls. A separate developer package remains available for testing.

CHANGES SINCE THE PUBLISHED 0.7.1 BUILD
- Eligible outdoor combat against a visible, hostile, opposing PvP-flagged
  player can create a guild report automatically. Added NPC, duel, free-for-all,
  sanctuary, instance, reload and cooldown safeguards. Reporting has a toggle;
  manual reporting remains available through /tw report and its keybinding.
- Condensed report tooltips and details: missing counts and scouting data are
  omitted. Available counts read "N combatants"; no empty snapshot placeholders.
- Recent nearby reports from different players increase pin size and a pulsing
  red halo. Repeated reports from one player cannot amplify a hotspot. Heat
  fades with age; pins use native crossed-weapon icons and a skull for heavy
  activity. Activity intensity does not claim exact team sizes.
- Updated the command board with Create Warband, automatic reporting controls
  and a paginated Help guide covering features, commands and bug reporting.
- Opening the board or enabling discovery no longer searches Group Finder.
  Search warbands and /tw find list existing warbands without joining them.
- Recruiting party leaders post in the rally zone's native Competitive entry.
  Fixed rallies retain their destination; Follow me tracks the organizer's zone.
  Secondary party leaders use that same rally. Unavailable or ambiguous zone
  matches pause posting instead of selecting an unrelated activity.
- Hardened invitation validation with active warband/session/party assignments,
  fresh recruit confirmation and expiration checks. Existing and externally
  edited Finder listings remain under their owner's control.
- Added clearer invitation request/result records and passive attribution of
  native invitation calls outside TotalWarcraft in /tw export. The export
  cannot identify which other addon or game UI initiated those calls.

COMPATIBILITY AND KNOWN LIMITS
- Built for WoW Forever only. OpenMap is optional; native map pins remain usable
  without it. TotalWarcraft does not change LayerSwap settings or auto-accept,
  leave, kick, or convert native groups. LayerSwap may pause its own hosting
  while a native Finder listing is active.
- The game controls transfers. Warband membership, group invitations and map
  positions do not guarantee a shared layer. No NPC GUID layer lookup is used.
- Enemy scouting is experimental and depends on a cooperating visible enemy
  and game-permitted delivery. Unavailable data is omitted, never fabricated.
- Offline protocol/package checks pass; native Finder, layering, cross-faction
  delivery and rendering remain dependent on live game behavior.
