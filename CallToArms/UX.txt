CALL TO ARMS 0.5.2-alpha UX

Testing controls: /cta control allow First Surname authorizes one named remote
controller for the session. /cta remote First Surname <verb> accepts status,
test-on/off, presence-on/off, report, capture-start/stop and snapshot. One verb
per command, five-second spacing, explicit result or 30-second timeout.
Remote report requires simulation mode. /cta control off stops access and
test/presence/capture. Reload revokes authorization. No game PvP flags change.

/cta report and its binding submit one report with no confirmation flow.
Reports go to the guild, filtered on actual ruleset, region and faction.
The sender sees a local submission; only remote receipt proves delivery.

Top-right toast: click for details; right-click dismisses. Details show zone,
coordinates, reporter, count/unknown count, snapshot summary, scope, expiry and
unknown layer. Show on map selects the report's zone outside combat.
Crossed-swords pins open the same details. Normally matching-zone only; optional
OpenMap projection covers its stitched map in mouse mode. No heat aggregation.

Test mode: session-only opt-in on both ends, [TEST] labels and purple pins,
four or more simulated participants including clearly counted synthetic filler.
Test reports use the existing report presentation, not production heat logic.
Normal sends: 120s cooldown, test sends: 10s, failed retries: 5s debounce.
Normal toasts: 30s spacing, test toasts: 5s. Muting suppresses toasts, not storage.
Reports expire after five minutes, store bounded to 64; test off clears tests.

Both players install the main addon. Bindings: Call to Arms -> Report PvP at my
location. An action-bar macro with /cta report works as well. Configure outside
combat. Layer coordination currently requires contacting the reporter manually.

The activity panel's Group locations switch and /cta presence on/off control
session-only self-location sharing with outdoor party/raid members. Defaults
off on reload/login. Green plus markers have hover details, no combat/report
action or notification. The peer list is separate from reports and never
creates heat or changes report counts. Unknown flags stay unknown; generic
combat is not player-versus-player evidence. /cta presence gives fresh/checked
nearby/unknown-range counts. Coordinates do not establish layer co-location.
