Field guide

FIELD GUIDE
< Back
Command board
1. Report an observed fight with Report PvP here. Guild WBP users receive a five-minute map marker. Two-minute cooldown; no automatic fight-size estimate. 2. Open Warbands and enable discovery. Start a rally, or join a listing. A warband coordinates up to four normal parties. WBP membership is separate from WoW's party invitation. The host attempts an invite; the recruit accepts it in WoW. 3. Open Recruitment to choose a suitable public activity, search or retry. Native API restrictions may prevent posting. You can also watch a known organizer by full character name. 4. Join the assigned party and travel to the rally zone. The game controls transfers; WBP cannot force or confirm a layer. Shortcuts: /wb report | /wb | /wb presence on/off /wb show | /wb finder | /wb find | /wb export | /wb clear All player features are available from the command board.
