CHANGES
- Preserve exact, case-insensitive TotalWarcraftReportComms membership.
- Snapshot legacy prefixed channels and request departure once per login.
  Stuck legacy memberships or an unreadable list cannot block the exact-name
  channel lookup/join. A join return alone never proves membership.
- Keep three join attempts in a 30-second window, with no idle channel ticker.
  Check actual membership before declaring a timeout. Log bounded cleanup
  counts and native join call outcomes without dumping native error text.
- Retry disconnected transport after combat, using the existing 30-second
  throttle. Do not replay failed reports or retry MUTED/BANNED channels there.
- Filter known routine UI_ERROR_MESSAGE types and exact localized messages
  before consuming the journal throttle/budget. Exact observed English variants
  cover missing localization globals. Do not discard generic error code 57:
  ERR_SPELL_FAILED_S may carry unknown actionable messages too.
- Count filtered UI messages in the existing header as uiErrorsFiltered.
  Unknown/restricted UI messages, Lua errors and blocked addon actions remain
  available. Other event listeners and native spell feedback are untouched.
- Detection evidence, flagged NPC acceptance, strict fallback, two-minute
  successful-send cooldown and one automatic attempt per combat are unchanged.

   The journal should record REPORT_CHANNEL_CLEANUP followed by a connection;
   a new connection also records REPORT_CHANNEL_JOIN attempt/result.
2. In qualifying combat, look for REPORT_ACTIVITY recipient=player or pvp-npc,
   then REPORT_ACTIVITY_CHECK evidence=observed-flagged-damage around five seconds
   and REPORT_AUTO accepted=true while combat is still active.

   receipt. Local send acceptance does not confirm delivery to another player.
   Your own report intentionally has no popup.

   journal. Export before /reload/logout, including startup and the full fight.
