WORKFLOW
Pushes to main and pull requests run .github/workflows/ci.yml. The workflow
installs the pinned Lua test runtime, runs every offline suite (including the
physically stripped production package), and saves the production ZIP artifact.

Pushing a new version tag runs .github/workflows/release.yml:
1. Require tag == tools/build_addon.py VERSION and reject alpha/dev tags.
2. Require WarbandPvP/CHANGELOG.txt to start with TotalWarcraft VERSION.
3. Build the production ZIP and run every test before exposing the upload token.
4. Fetch CurseForge's exact Forever 1.60.1 version ID (type 88568); never guess
   another flavor/version. Upload to project 1819796 with releaseType=release
   and automatic publication after moderation. Upload the packaged changelog.
5. Save the file ID, public URL and archive hash in the Actions run summary and
   artifact. Moderation and CurseForge app indexing remain external processes.

The custom compiler is required to remove --@dev regions and developer-only
modules. Raw source packaging does not understand these directives. Keep
CurseForge Source > Automatic Packaging set to No automatic packaging to avoid
duplicate or unfiltered tag builds. The GitHub source link stays connected.

ONE-TIME CREDENTIAL
Create a CurseForge upload token in the author account. Put it directly in
https://github.com/KDotIV/TotalWarcraft/settings/secrets/actions/new
Name: CF_API_TOKEN
The GitHub connection alone does not provide this API credential. Never commit
the token. The pipeline injects it only into the upload step, uses a header,
refuses redirects, and never logs the credential or raw error responses.
CF_API_TOKEN was configured and used successfully on November 21, 2026.
The workflow is not capable of uploading if that secret is removed or expires.
